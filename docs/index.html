🐳 termdock

Split your terminal into panes, run several shells side by side, and leave them running in the background — reattach later from another terminal, or another machine, without losing a thing.

Download the latest release Source on GitHub

Install

Pick the one for your system. Every release ships packages and archives for linux and macOS, amd64 and arm64.

Debian / Ubuntu

curl -LO https://github.com/padovanl/termdock/releases/latest/download/termdock_linux_amd64.deb
sudo apt install ./termdock_linux_amd64.deb

Fedora / RHEL

sudo dnf install ./termdock_linux_amd64.rpm

Alpine

sudo apk add --allow-untrusted ./termdock_linux_amd64.apk

With Go

go install github.com/padovanl/termdock@latest

The exact filenames carry the version — check the latest release for the ones to download. Then just run termdock.

What it does that tmux doesn't

Not a tmux wrapper: it manages the pseudo-terminals and runs its own VT100 emulator, scrollback and all.

🔍 Fuzzy jump picker

Type to filter every window and pane in the session, with a live preview of the one you're about to jump to.

🖼️ Live pane overview

Every pane in the session at once, as a grid of live thumbnails. Click or arrow to the one you want.

🔎 Search everything

One search across every pane's scrollback in every window, plain text or a regex, jumping straight to the hit.

⚙️ Settings, live

Change any setting from inside a running session and see it immediately — optionally saving it back to your config.

🎨 Themes built in

Eleven colour presets compiled into the binary. No plugin manager, nothing to install.

💾 Survives a reboot

Layout and working directories are snapshotted continuously and restored next launch — no plugin required.

🪟 Floating popup

A scratch terminal over whatever you're looking at, that keeps running when you hide it.

🖱️ Mouse throughout

Click to focus, drag borders to resize, drag tabs to reorder, drag a pane's title into another window.

Getting started

Everything is behind the prefix key, Ctrl-B, exactly as in tmux.

KeysWhat happens
Ctrl-B ?Every keybinding there is — start here
Ctrl-B v / sSplit the pane side by side / stacked
Ctrl-B then arrowsMove the focus between panes
Ctrl-B cNew window
Ctrl-B gThe live overview of every pane
Ctrl-B wFuzzy-jump to any window or pane
Ctrl-B /Search every pane's scrollback
Ctrl-B CSettings — change them live
Ctrl-B PThe floating popup terminal
Ctrl-B dDetach; the session keeps running

Back later, from anywhere:

termdock ls                 # what's still running
termdock attach -t main     # pick up where you left off

Configuration

Optional, and you never have to write it by hand.

Ctrl-B C lists every setting with its current value; Enter edits one live, S edits it and saves it to ~/.config/termdock/termdock.conf. Or write it yourself:

# ~/.config/termdock/termdock.conf
theme dracula            # 11 built in — run "termdock themes"
mouse on
history-limit 10000      # scrollback per pane
status-segments git,battery
bind M jump-picker       # rebind any command

A commented example ships with the packages, at /usr/share/doc/termdock/termdock.conf.example.
